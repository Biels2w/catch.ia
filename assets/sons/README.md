# Sons do Catch.IA

Recursos sonoros sintetizados em Python com apoio do ChatGPT para este projeto.
Os arquivos não utilizam gravações ou músicas de terceiros.

## Arquivos

- trilha_refugio.wav: trilha ambiente sintética de suspense, 32 segundos, estéreo, preparada para repetição.
- abrir_arquivo.wav: efeito de abertura de papel.
- fechar_arquivo.wav: efeito de fechamento de papel.
- virar_pagina.wav: efeito de passagem de página.
- luz_ligar.wav: clique do interruptor ao ligar.
- luz_desligar.wav: clique do interruptor ao desligar.
- campainha.wav: toque metálico da campainha do balcão.

Todos os arquivos usam WAV PCM de 16 bits a 22050 Hz.
O volume final é controlado pelo módulo de áudio do jogo.

## Instalação

Extraia este pacote na raiz do projeto, preservando assets/sons/.
O README desta pasta substitui a orientação genérica anterior.
