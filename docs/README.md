# Documentação do Catch.IA

Esta pasta reúne os documentos de planejamento do Catch.IA, jogo de investigação desenvolvido em Python com Pygame para a disciplina de Introdução a Algoritmos/Programação.

## Proposta do jogo

A [proposta do Catch.IA](proposta.MD) apresenta o tema, os objetivos, as regras, os controles e o escopo planejado. Ela também explica como a análise de documentos e respostas faz parte da investigação para identificar humanos e IAs disfarçadas.

Se o grupo mudar alguma regra, controle ou parte do escopo durante o desenvolvimento, a mudança deve ser registrada na proposta.

Para consultar o estado atual do jogo e as instruções de execução e testes, acesse o [README principal](../README.md).
