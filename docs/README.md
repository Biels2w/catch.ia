# Documentação do Catch.IA

Esta pasta reúne o planejamento do projeto.

- [proposta.MD](proposta.MD): tema, integração com a jogabilidade, participantes, regras, controles, organização do código, escopo e originalidade.

A proposta foi atualizada para descrever 10 personagens disponíveis e 10 atendimentos sem repetição em um turno completo. Uma derrota pode encerrar a partida antes desse total.

O [README principal](../README.md) explica instalação e funcionamento. O [README de src](../src/README.md) apresenta as responsabilidades dos módulos e uma sequência para explicar o código.

Mudanças futuras nas regras devem ser refletidas na proposta e nos documentos das pastas afetadas.
